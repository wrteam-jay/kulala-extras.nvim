1. Introduction                                     *kulala-extras-introduction*

kulala-extras.nvim adds response history and a diff-based compare view on
top of kulala.nvim (https://github.com/mistweaverco/kulala.nvim), using its
public `require("kulala.api").on("after_request", ...)` hook.

==============================================================================
2. Setup                                                   *kulala-extras-setup*

>lua
    require("kulala-extras").setup({

      -- max_history_per_request = 50,

==============================================================================
3. Commands                                             *kulala-extras-commands*

                                                *:KulalaExtrasCompareHere*
:KulalaExtrasCompareHere    Diff the two most recent responses for the
                             request under the cursor. One step, no
                             picker - the common case.

                                                   *:KulalaExtrasOpenHere*
:KulalaExtrasOpenHere       Browse past responses for the request under
                             the cursor with a live preview
                             (status/headers/body) via snacks.nvim if
                             installed. Falls back to a plain list (no
                             preview) without snacks.nvim. Enter opens
                             the selected one in kulala's own native
                             response window (Body/Headers/Verbose/
                             Report) - see the README's "Privacy" and
                             "Fragility" sections.

                                                    *:KulalaExtrasCompare*
:KulalaExtrasCompare        Full picker: pick a request, then two past
                             responses, and diff them in a native Neovim
                             diff split.

                                          *:KulalaExtrasClearHistoryHere*
:KulalaExtrasClearHistoryHere  Clear history for the request under the
                                cursor.

                                              *:KulalaExtrasClearHistory*
:KulalaExtrasClearHistory   Clear all recorded history, every request.
                             Asks for confirmation first.

                                                *:KulalaExtrasDebugPayload*
:KulalaExtrasDebugPayload   One-shot: print the raw `after_request`
                             payload of the next response you run.

==============================================================================
4. Sign column                                       *kulala-extras-signs*

A dim `|` marks every request in the buffer that has recorded history. A
highlighted `>` tracks the cursor across every request (using kulala's
own parser, not text matching), showing which one kulala would run
next - and, being cursor-based, which one the *Here commands above act
on too. Requires 'signcolumn' to be visible - set automatically to "yes"
on FileType http/rest.
